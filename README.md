# 面试知识卡 · Interview Knowledge Cards

线上网站继续作为日常使用入口：手机和电脑用同一账号访问已部署的 HTTPS 网站，共用线上题库；不需要电脑开机、连接同一个 Wi-Fi 或安装本机证书。iPhone 主屏幕使用方式见 [手机说明](docs/ios.md)。

Windows 客户端使用本地 SQLite，2.1.0 起可与网站自动双向同步。网站「设置 → 网站同步」生成连接码，在客户端填写网站地址和连接码，核对账号与题库数量，确认首次合并后启用。手机在网站修改题目和答案，电脑联网且软件运行时自动接收；电脑离线修改保存在本地，联网后自动上传，不要求同一 Wi-Fi。首次合并前自动备份，同字段冲突保留双方供选择。详见 [自动同步说明](docs/cloud-sync.md) 和 [本地软件说明](docs/desktop.md)。未连接的两份题库保持独立，不直接覆盖。

**2.2.0 使用增量同步**：空闲只检查账户游标，普通更新仅拉取变更记录；上传按记录合并和校验必要引用，成功后无需全量复核。网页和客户端的后台刷新也使用增量。已有连接自动迁移，保留原题库、设备授权和待发送修改，不用重新配对。首次连接或恢复后核对才读取完整快照。

**2.2.1 优化卡片保存**：手机网页与 Windows 客户端编辑、新增知识卡时，只提交修改字段，服务端只读取当前卡片和必要关联，返回当前卡片后在页面中替换，不再重新读取和下载整个题库。版本冲突保护、原始来源、历史和自动同步保持；配对手机的离线编辑也兼容这一入口。

**2.3.0 优化导入与资料管理**：普通导入、来源和被问记录、问题关系及项目／分类维护都按涉及的记录校验保存，新版页面只补回变化记录。批量导入与同步回执分组写入，容量检查使用事务计数；导入列表只读摘要，展开单条再读内容。删除卡片和项目只加载其依赖，保留删除前确认及追问重挂；项目导出只读所选项目，图谱只取标签和连接。升级不改变题库与同步授权。

把面试问答整理成按项目分类的知识卡，在电脑和 iPhone 上复习、改写答案，并用图谱找回问题之间的联系。

**v1.0.0** 提供账户密码登录、独立用户题库、人工维护、AI 直接导入和项目离线复习。个人题库保存在数据库里，仓库只包含源码、配置模板和虚构的演示资料。

## 可以做什么

| 功能 | 使用方式 |
| --- | --- |
| 项目书架 | 按项目浏览卡片、右键快捷操作；支持删除整个项目及其中的卡片，删除前显示数量并二次确认 |
| 知识卡 | 问题、口述提纲、完整答案与重点属性；支持卡片／纯题目列表切换，标题和问题渲染 Markdown |
| 面试来源 | 同一道题记录多次出现，保留当时的问法、回答、公司、岗位和轮次 |
| 翻卡自测 | 全库或指定题库发问，支持顺序／随机切换、访问历史；有无追问时底部操作栏保持位置；卡片内可直接编辑或删除；掌握标记立即反馈并后台保存 |
| 知识图谱 | 参考 Obsidian 的白底灰色节点与细线，支持拖动节点、悬停关联、单击打开、滚轮缩放与自然收敛布局；显示和力参数可调 |
| 卡片维护 | 右键卡片／题目行，或点击「⋯」打开编辑、收藏、重点、掌握状态和删除菜单；完整答案默认收起 |
| 导入问题 | 人工填写多道问答后直接导入，或下载 JSON 模板、上传文件自动解析入库；结果和内容保留在记录中 |
| 备份与恢复 | 独立页面下载完整 JSON／Markdown 阅读版，上传完整备份后预览恢复 |
| AI 协作 | 受保护的机器接口查询管理员题库、直接导入普通题目并查询结果；不能删除、恢复或管理用户 |
| 私人账户 | 邮箱账号加密码注册，每人拥有独立题库；管理员控制用户启停和注册开关 |
| 离线复习 | 下载指定项目后，断网阅读、翻卡和查看图谱；修改需要联网 |
| 网站与客户端同步 | 连接码授权后自动双向同步题目、答案和复习状态；断网补传、冲突选择、网站撤销设备；手机使用公网网站，无需同一 Wi-Fi |

题目和答案的 Markdown 支持中文标点紧邻加粗或斜体标记，例如 `**提示：**后接中文`、`正文**（条件）**继续`，无需手动插入空格。翻卡自测、详情、追问和导入记录共用相同规则；代码中的星号及明确转义的标记仍显示原文。

删除知识卡、删除项目、移除问题关联、移除本机离线内容、移除待导入题目，以及完整备份恢复都需要在独立弹窗中再次确认。取消、关闭或按 Esc 不会执行删除；处理中禁止重复提交。删除项目会移除其中的全部卡片（包含归档卡片）及其关联，保留原始来源、共用知识点和其他项目。删除后可通过此前导出的完整 JSON 备份恢复。

首页项目卡、侧边栏项目、知识卡和题目列表支持右键菜单；手机使用项目或题目旁的「⋯」。网站内禁用浏览器默认右键菜单，空白处右键不弹出菜单。自定义菜单支持方向键、Home／End、Enter 和 Esc，滚动页面或点击菜单外会关闭。

右上角显示连接状态及保存进度，不再提供手动刷新题库按钮。左侧项目较多时可滚轮滚动或拖动细绿色滚动条；轨道融入侧栏背景，悬停或键盘操作时滑块加深。

项目菜单还可修改名称与说明、开始复习、下载离线内容或导出题库 JSON。题库导出包含该项目的活动及归档题目、相关来源和内部连线，可在「导入问题」上传；完整账号备份仍在「备份与恢复」中下载。

同一账号内不能新建或改名为已有的项目名称，名称前后空格不计入区别；网页、JSON 和 AI 导入也遵循此规则，不同账号互不影响。已有重名项目保留原样，仍可编辑内容或改成不同名称。

「首页」直接展示欢迎区、开始复习入口和统计，不显示顶部面包屑与连接状态栏，按整屏可用高度展开。手机通过欢迎区右上角的导航按钮打开侧栏，文字与插画上下排列、统计改为两列，并为浏览器工具栏和安全区域留出空间；较矮的屏幕优先缩小装饰，内容超出时可正常滚动。其他页面保留顶部导航。「全部项目」展示我的项目书架。左侧项目右侧的拖动手柄可调整顺序，也可聚焦手柄后按上下方向键移动，Escape 取消拖动。松开后立即更新显示并自动保存到当前账号；侧栏和全部项目使用同一顺序，刷新和换设备保持一致，保存失败会提示并恢复已确认的顺序。新项目追加在已排序项目之后。

项目顺序保存在可选的 `sort_order` 字段中，旧数据继续按内部 ID 排列；完整备份、项目导出和离线快照包含顺序。旧格式的普通导入或项目改名不会清除手动顺序。`PUT /api/v1/projects/order` 使用当前题库版本及完整项目 ID 列表保存，仅允许网页账户操作，返回项目及版本，不读取或返回整库答案。

知识卡详情中的「追问」默认只显示问题，点击后在原处展开口述答案，完整答案仍默认收起。「添加追问」可新建带独立答案的卡片，或关联已有卡片；追问可以单独编辑、标记掌握，移除关联仍需二次确认。自测以主问题分组，「继续追问」依次展示追问并隐藏答案，可返回主问题；「下一题」直接切换到下一组，不要求答完全部追问。自测卡片右上角「编辑」可修改当前主问题或追问的题目、复习提纲和完整答案，保存后仍停留在原复习位置；未保存关闭时会提示保留或放弃。离线时可阅读，修改需联网。按题库自测只包含所选题库，父卡不在该范围时，追问可以作为独立主问题复习。

自测卡片右上角「删除」对当前主问题或追问生效，先显示题目与影响范围，再二次确认。取消或删除失败不会跳题；成功删除追问后返回主问题，删除主问题后接续剩余问题，并从复习历史中移除已删题。删除有追问的题目时，按现有追问顺序将第一条未归档追问提升为主问题，其余追问归到它下面；若删除的是嵌套题目，第一条追问接续原来的父问题位置。接替题目已有的子问题仍保留，卡片内容、重点和掌握状态不变。切换后的答案重新隐藏；当前范围删空时可重新选择题库。离线、复习标记正在保存或其他保存操作期间不能删除。

题库卡片、题目列表与详情标题优先展示本卡的独立问题，卡片内不再上下重复展示标题和同一道问题。主问题与追问的关联在详情中查看，追问标题不拼接原来的整道组合题。

已核对来源的题目显示独立来源徽标，与「待复习」「重点」并列；题目列表、展开的追问、详情和翻卡自测也显示本题自己的来源。六类为「面经原题」「面经拆问」「原题改编」「仅记主题」「其他来源」「扩展练习」。原题改编包含新增内容，仅记主题不视为具体原题；扩展练习表示在本次提供的材料中未见对应提问。未核对的卡片不自动推断来源，也不会继承主问题的来源。

知识点只维护**知识大类**，例如 MySQL、Redis 与缓存、计算机网络。编辑卡片、添加追问和填写导入均使用下拉单选，可选择“未分类”；新增或改名在“维护与备份 → 知识大类”完成。题目筛选、卡片标签、首页计数和图谱只显示在用大类。旧的细分类以 `topics[].archived: true` 归档保留，不再列出。

Windows 安装版从 2.0.2 起支持自动检查和后台下载，在“设置 → 软件更新”中重启安装。更新前备份本机 SQLite，并保留题库、账户及手机配对；旧版只需首次手动升级到含更新器的安装版。便携版可免安装运行，更新行为及发布方法见 [桌面版说明](docs/desktop.md)。

来源标注通过保留的 `source-audit-YYYYMMDD-*` 标签存储，随备份、项目导出和离线下载保留，不列入分类下拉框。修改卡片分类不会移除来源标记。标注依据与逐题对照表保存在私人目录，不提交真实面试材料。

项目和首页的问题数量统一按主问题统计，子问题默认折叠在主卡下面；卡片和列表都可展开。搜索或筛选命中子问题会自动展开所属主卡。`npm run preview:groups` 可启动本机只读预览，使用方法及统计边界见 [主问题分组预览](docs/主问题分组预览.md)。

题库入口是范围明确、可以直接用于面试的问题，追问沿着上一题继续深入；同主题但没有自然承接关系的题独立展示。项目与标签负责分类，不为分组新增宽泛的总括题。同一追问只保留一个直接父问题，跨知识点使用相关关系。整理与导入遵循 [题库组织规范](docs/题库组织规范.md)，改写问题时同步对齐对应答案。

日常题库接口不加载全部历史答案（`revisions` 为空），新增或编辑仍保存历史记录；完整 JSON 备份包含历史，按单卡查询或恢复的接口仍保留。备份输出直接使用同一次数据库快照，避免反复解析整库历史造成资源超限。

## 本机运行

需要 **Node.js 22.13+ 或 24 LTS** 和 npm。建议使用 Node.js 24；Cloudflare 账户只在部署上线时需要。

```sh
git clone https://github.com/Wahuwahuuu/interview-knowledge-cards.git
cd interview-knowledge-cards
npm ci
npm run setup
npm run build
npm run db:local
npm run preview
```

打开 <http://127.0.0.1:8787>。新数据库第一次显示管理员密码设置，默认本机管理员账号为 `admin@example.com`；这是独立的本机测试账户。随后在「维护与备份 → 导入问题」上传 [demo-import.json](examples/demo-import.json)，自动导入后就能体验两个示例问题及一条追问关系。

Windows 也可以双击 **启动本地预览.cmd**；它会准备依赖、配置和数据库。关闭启动窗口即可停止预览。本机模式仅监听回环地址，不能作为手机共享或生产部署方式。

开发时使用 `npm run dev`。离线验证请使用构建后的 `npm run preview`，而非 Vite 开发页面。`npm run setup` 只创建缺失的配置，不覆盖已有部署。

## 部署到 Cloudflare

使用自己的 Workers、D1 和 Cloudflare Access，平台提供 `workers.dev` 网址。先从免费额度起步，额度与计费以自己的账户设置及 [Workers](https://developers.cloudflare.com/workers/platform/pricing/)／[D1](https://developers.cloudflare.com/d1/platform/pricing/) 官方说明为准。

1. 在 `wrangler.jsonc` 设置自己的 `OWNER_EMAIL`，授权部署工具。
2. 执行 `npm run deploy -- --bootstrap`，初始化独立 Worker、D1 和部署记录。
3. 配置 Access 管理员邮箱验证与单独的 AI 服务入口，再发布。
4. 管理员在网页亲自设置密码，随后将人工 Access 保护范围缩到 `/bootstrap-admin/*`，开放网站自己的登录和注册页。

完整命令、最小权限、手动配置方法与后续更新见 [部署指南](docs/deployment.md)。配置文件和部署身份记录都留在本机，不提交到仓库。Linux/macOS 可使用命令行运行和部署；Windows 提供额外的一键脚本及服务凭证加密保存。

## 账户与隐私

- 新用户注册后从空题库开始，卡片、来源、草稿、版本、导出和恢复都限定当前账户。
- 管理员拥有自己的题库，并可启停普通用户、开关注册；用户管理页不提供他人题库浏览。
- 密码使用随机盐 scrypt；会话 Cookie 为 HttpOnly、Secure、SameSite=Lax，服务器只保存会话凭证摘要。改密和停用会撤销旧会话。
- Access 邮箱验证仅用于管理员首次设置，普通用户使用账号密码。AI 使用独立服务凭证，绑定管理员题库。
- 切换账号或退出登录清理本机离线题库；离线退出先清理数据，联网后撤销旧会话。

普通用户邮箱目前只作为账号标识，v1.0 没有邮件验证或忘记密码找回流程。账户与密码、管理员用户管理位于左下角退出按钮左边的齿轮设置窗口，不再混在维护页面。账号操作说明见 [账户指南](docs/accounts.md)。

## 导入问题与 AI 协作

在「维护与备份 → 导入问题」选择现有题库或新建题库，填写标题、问题、复习提纲（口述版）和完整答案（详细讲解），可一次添加多道题。内部编号由程序生成，答案可以稍后补充。点击「导入题目」直接保存，成功后清空本次表单；失败保留填写内容。切换导入与备份页面时保留填写内容。

JSON 是辅助入口：下载模板或上传 JSON 文件，程序自动解析、校验并直接导入。AI 提交也直接入库，不再进入人工确认环节。完整备份使用独立的「备份与恢复」页面，仍先预览并二次确认；普通导入和完整恢复的记录分开展示。维护页不再单列面试来源，已有来源内容仍随题目与备份保留。

JSON v1 包含 `projects`、`topics`、`cards`、`sources`、`occurrences` 和 `relations`。`batch_id` 是稳定批次标识；相同批次重复提交不会生成重复卡片。所有引用需要存在于题库或同一批数据里。更新已有对象时须带上读取到的当前完整对象及 `revision`、`updated_at`，避免覆盖新答案或复习标记。无关题目的并发变化由服务端有限重试；同一对象过期则明确报错。

人工可以上传 JSON；配置独立机器凭证后，AI 可调用：

| 方法 | 接口 | 权限 |
| --- | --- | --- |
| GET | `/api/v1/agent/library` | 查询管理员当前题库，不返回历史快照 |
| GET | `/api/v1/agent/schema` | 查询 JSON Schema |
| POST | `/api/v1/agent/imports/submit` | 直接导入普通题目并返回结果 |
| GET | `/api/v1/agent/imports/{id}` | 查询批次状态与差异 |

旧机器路径 `/api/v1/agent/imports/preview` 作为兼容入口也会直接导入。机器凭证不能调用人工编辑、删除、账号管理或完整恢复接口。普通用户可以让 AI 整理 JSON，登录自己的账号后上传到自己的题库。

详见 [格式与接口说明](docs/AI导入说明.md)、[AI 整理提示词](docs/AI整理提示词.md)、[演示文件](examples/demo-import.json) 和 [空白模板](examples/import-template-v1.json)。完整导出可恢复卡片、来源、关系和历史；操作见 [备份恢复](docs/backup-restore.md)。

「导入记录」显示「已导入」「导入失败」等结果，点击记录可展开内容，不再显示确认或重新预览按钮。格式错误会即时提示；通过结构校验但保存失败的批次保留失败原因，可在问题解决后点击「重试导入」。普通导入要么整批保存，要么不写入部分题目。旧待确认记录显示「未导入」，查看时不执行；可主动点击「导入这条记录」，已有取消记录保持取消。

记录内展示**标题、问题、复习提纲、完整答案**，答案按 Markdown 排版，更新提供前后对照，题目默认收起。知识点、来源、问题关联和系统字段仍收在「其他导入资料」中。备份恢复的待确认记录保留预览、取消与独立二次确认；题库变化后先刷新预览，再次核对后才能恢复。

首页「开始一轮复习」先选择「全库发问」或「按题库发问」，再选择出题方式。项目里的翻卡入口会预选该题库。顺序出题优先按标题开头的题号排列，没有题号时按稳定 ID 自然排序，保存掌握状态不会打乱顺序；全库按题库分组。随机出题在一轮内避免重复，上一题返回实际访问历史。复习中可随时切换方式，当前题保持不变，下一题按新方式发问。归档题不参与复习，离线时范围限于本机下载内容。左上页面名称可点击跳转。

掌握、收藏和重点标记点击后立即更新显示，同时提示正在保存。保存期间可以继续切题、连续标记，也可以修改刚才的选择；后台按顺序确认，重复点击会合并。失败时撤回尚未确认的显示并提供「重试保存」，重试先读取最新题库再提交状态。未完成保存时关闭或刷新页面会提示；离线仍只允许阅读。

状态更新使用登录用户专用的 `PATCH /api/v1/cards/{id}/state`，只接受 `mastery`、`favorite`、`important` 与题库／卡片版本号，返回当前卡片状态及题库版本。服务端仅查询与更新一张卡片，保留答案版本、历史和其他资料；完整编辑与导入继续使用原有接口及并发保护。机器凭证不能调用状态写入。

知识卡详情中的「删除知识卡」会先打开独立确认弹窗，核对题目后点击「确认删除」才执行；取消、关闭或按 Esc 都不会删除。删除会清理该卡片的来源关联和问题连线，原始来源及其他题目保留，并更新当前设备已下载的副本。需要恢复时可使用删除前的完整备份。卡片不再显示版本号、历史浏览或恢复入口；完整答案默认收起，展开后才解析正文。

## iPhone 和离线

用 Safari 打开自己的部署地址，登录后通过分享菜单添加到主屏幕。进入项目，点击「下载项目」，看到成功提示后即可断网复习。

离线内容标明下载时间，需要更新时联网手动下载。离线不能修改答案、收藏、掌握状态或来源记录，也不会把未保存操作排队上传。步骤和检查清单见 [iPhone 使用指南](docs/ios.md)。

## 技术和目录

React + TypeScript + Vite 构建前端；Hono 运行于 Cloudflare Workers，D1 保存普通关系表；Canvas 绘制图谱，独立 Web Worker 使用 d3-force 计算布局，Service Worker 与 IndexedDB 保存页面外壳和用户选择的项目快照。

```mermaid
flowchart LR
  Human[电脑 / iPhone] --> App[React 网页]
  App --> Worker[Workers / Hono]
  Worker --> D1[(D1 用户题库)]
  App --> Offline[本机离线项目]
  AI[AI 整理工具] --> Access[Access 服务认证]
  Access --> Worker
  Worker --> Result[直接导入与结果记录]
  App --> Restore[备份恢复预览与二次确认]
  Restore --> Worker
```

| 目录 | 内容 |
| --- | --- |
| `src/` | 页面、编辑器、图谱、账户及离线逻辑 |
| `worker/` | 登录授权、维护接口、D1 事务与版本冲突 |
| `shared/` | JSON 契约、数据校验、图谱和差异生成 |
| `migrations/` | 初始题库与多用户迁移，旧数据归属管理员 |
| `scripts/` | 配置、运行、部署、AI 导入与验证工具 |
| `examples/` | 虚构演示数据和导入模板 |
| `docs/` | 部署、账户、AI、备份、手机与验证说明 |

## 验证与发布

```sh
npm run build
npm test
npm run test:api
npm run test:accounts
```

接口验证使用独立本地 D1 数据库；账户测试自动生成虚构的旧版题库，检查迁移、隔离、登录、改密和用户管理，无需个人备份。线上检查为手动运行，需要自己的部署与授权；不会由 CI 自动发布网站。

v1.0 的桌面离线、原文保留、备份恢复、并发冲突、跨用户隔离和真实线上注册登录已完成验证。**iPhone 真机登录与离线复习仍需在实际设备完成验收**。详细记录与边界见 [验证说明](docs/validation.md)，版本说明见 [CHANGELOG](CHANGELOG.md) 与 [GitHub Releases](https://github.com/Wahuwahuuu/interview-knowledge-cards/releases)。

本版采用手动复习，尚未提供间隔重复算法或每用户独立 AI 凭证管理。Windows 支持本地编辑及联网后同步网站；公网网站的项目下载仍是离线阅读副本，离线编辑仅限可选的本机配对 PWA。
