# Windows 本地软件与 iPhone 离线编辑

手机日常使用公网网站，参见 [iPhone 网站使用说明](ios.md)。2.1.0 起客户端可与网站自动双向同步，不需要同一 Wi-Fi；连接步骤、冲突处理和范围见 [网站同步说明](cloud-sync.md)。首次合并前核对账号并自动备份；未授权连接时两份题库保持独立。下文的手机局域网配对是另一种可选方式，不是使用网站的前提。

## Windows 使用

打开 `releases/Interview-Knowledge-Cards-2.2.1-Setup.exe` 安装，或直接运行同目录的 `Portable.exe`。安装包包含运行环境，不需要另外安装 Node、MySQL 或 SQLite 服务。升级程序不覆盖题库；卸载默认保留数据。便携版可以免安装运行，需要自动更新时使用安装版。

默认数据目录：`%APPDATA%\InterviewKnowledgeCards`。

- `knowledge-cards.sqlite`：所有账户、题库、归档、来源、关系、历史、导入记录及同步日志。
- `backups/`：每天首次启动的 SQLite 备份，以及完整恢复前的备份。备份暂不自动删除。
- `certificates/`：这台电脑的本地连接证书及私钥。只把公开根证书安装到自己的手机，不要分享整个文件夹。
- `agent-credential.json`：仅供本机 AI 普通导入的凭证；不提供删除、恢复或用户管理。

2.2.0 正常同步只读取变化记录和必要引用，不因修改一题重新下载整库；已有设备授权和待发送内容自动迁移。首次连接及恢复后的重新核对才读取完整快照。

2.2.1 的卡片编辑与新增也只提交改动字段、返回当前卡片，不在保存后重新读取整库；本机和网站共用按记录校验、历史及事务同步日志，现有同步连接不变。

网站同步连接和待发送操作保存在本机 SQLite，设备令牌使用当前 Windows 用户加密。关闭软件停止同步，题库和待同步内容仍保留；重开并联网后自动继续。首次连接在齿轮 → **网站同步**操作。电脑访问公网需要已有代理时，可在该页“网络设置”填写本机 HTTP 代理地址；无代理时留空。

通过程序的“文件”菜单可以打开数据目录和备份目录。完整 JSON 与阅读版 Markdown 导出、恢复预览及二次确认继续保留。SQLite 文件应通过自动备份复制，或关闭程序后复制，避免遗漏正在使用的 WAL 日志。完整数据库包含所有账户；不要公开上传。

普通整理题库不需要 GitHub、Cloudflare 或外网；需要远程 AI 时，该服务自身仍需联网。Windows 安装包尚未购买代码签名证书，系统可能显示未知发布者。

## 自动更新

2.0.2 开始，Windows **安装版**在启动时及运行期间每两小时检查正式新版本，在后台下载并校验安装包。下载成功后提示，在左下角齿轮 → **软件更新**查看进度并点击“重启更新”；也可从程序“帮助”菜单手动检查。下载不会强制退出当前复习，普通退出不会绕过备份自动安装。

旧版本没有更新器，需要首次手动安装 2.0.2 或以后的安装版；以后发布的新版本即可在客户端更新。便携版、直接运行解压目录和开发模式不执行自动替换，可以随时换用安装版；默认数据目录相同，已有题库继续使用。最新版安装包见 [GitHub Releases](https://github.com/Wahuwahuuu/interview-knowledge-cards/releases/latest)。

更新前必须保存正在编辑的卡片或导入已填写的题目。客户端先暂停新写入、等待已提交操作完成，生成 `backups/before-update-版本-时间.sqlite`，再关闭 SQLite 和本机连接并启动安装器。备份失败时不安装。备份保留全部账户、题目、答案、主追问、复习标记、导入与历史、手机配对和同步记录。安装程序只替换程序目录，不恢复或覆盖 SQLite；手机尚未同步的修改仍保存在手机，重新连接后继续同步。

更新来源为本项目公开的 GitHub Releases，下载校验沿用更新器生成的 SHA-512 清单，只安装正式新版本，不自动降级。客户端不包含 GitHub 发布令牌。无法连接更新服务器时显示可重试状态，日常本地功能仍可离线使用。

2.0.3 补充下载停滞保护：连续两分钟无下载进度时中止本次传输，显示可重试状态；持续有进度的慢下载不会被提前中止，未完整下载的安装包不会进入可安装状态。

知识点现按大类维护，卡片编辑和填写导入均为下拉单选。分类整理随普通双向同步传到手机；手机重新连接电脑并完成同步后使用新大类。旧细分类和来源元数据仍在备份、历史中保留。

## 可选：局域网首次连接 iPhone

1. 保持电脑软件运行，手机与电脑连接同一个 Wi-Fi。点击电脑左下角齿轮 → **本机与局域网**。
2. 选择电脑的实际无线网卡地址，使用 iPhone Safari 扫描二维码。二维码只包含连接说明的网址，不包含题库凭证。
3. 在说明页下载本机根证书，到 iPhone 设置 → 已下载描述文件，安装证书。再到设置 → 通用 → 关于本机 → 证书信任设置，打开对这张证书的完全信任。核对手机证书指纹与电脑显示一致。[Apple 的证书信任说明](https://support.apple.com/en-us/102390)。
4. 打开说明页的 HTTPS 知识卡地址，通过 Safari 分享菜单“添加到主屏幕”。**从主屏幕应用打开后再配对**；Safari 与主屏幕应用可能使用不同的存储空间。
5. 电脑点击“生成配对码”。在主屏幕应用里输入设备名称和配对码，等待页面资源和题库保存完成。配对码五分钟有效，仅可使用一次。

如果 Safari 提示 HTTP 地址被“仅限 HTTPS”阻止，不必寻找或关闭 Safari 安全开关。已安装并信任证书时，直接使用电脑设置里显示的“手机应用”HTTPS 地址。首次安装时，可以在电脑下载说明页中的公开根证书 `.cer`，或由维护者导出同一份公开根证书，作为邮件附件发送给自己，用 iPhone 自带“邮件”打开，再到设置安装并手动信任；核对证书名称、指纹与当前电脑一致。只传公开证书，不传整个 certificates 目录或私钥。[Apple 的证书分发说明](https://support.apple.com/zh-cn/guide/deployment/depcdc9a6a3f/web)、[描述文件安装步骤](https://support.apple.com/zh-cn/102400)。

配对后的 PWA 可在电脑关闭时阅读、编辑、新增题目、修改掌握/收藏/重点、维护主追问及导入普通 JSON。所有删除仍弹窗二次确认。完整备份恢复、用户管理和密码修改在电脑客户端进行；手机可以导出含待同步操作的设备备份。

## 可选配对 PWA 的日常同步

修改首先提交手机的 IndexedDB；页面右下角显示“本机已保存 · N 项待同步”。电脑在线且同网时，打开应用、回到前台、编辑后或点击“立即同步”会进行双向同步。电脑提交 SQLite 后才移除待同步项，并拉回电脑上的改动。iOS 不保证后台任务一直运行；请在前台等到“已同步到电脑”。

手机完整副本同时保留归档、来源、历史和导入记录，因此比仅下载在用题目的阅读副本更大。当前题库完整同步数据约 23.6 MB（未计浏览器存储开销），不含视频或大附件；首次配对需要等待这些资料保存完成。

不同字段的修改自动合并，例如电脑修改讲解、手机标记已掌握。同一字段改成不同内容会显示两份，支持采用电脑内容、保留手机内容或编辑合并。删除与编辑冲突也要处理，旧手机不能自动复活已删除题目。一次有关联的操作整体提交，不写入半份关系。

完整恢复后，电脑会切换题库代次。手机旧操作不会盲目覆盖恢复结果；到同步界面逐项选择保留或放弃，或先导出设备备份。解除配对前必须处理待同步项，并再次确认清除手机副本。撤销设备只撤销同步权限，不会远程抹去手机已有资料。

## 地址变化、空间与连接问题

- 建议在路由器里为电脑固定 DHCP 地址，保持 PWA 地址稳定。IP、端口或 HTTPS 地址变化会产生新的浏览器存储空间。先从旧主屏幕应用导出**设备备份**，在新地址的配对页导入，即可接续待同步操作。恢复文件包含私人数据及设备凭证，请本地保管。
- Windows 防火墙首次提示时，只允许自己信任的网络。默认连接端口为 HTTPS `47392`、证书说明页 `47393`；题库的电脑接口 `47391` 只监听回环地址。不要把端口映射到公网。
- 校园/访客 Wi-Fi 可能隔离设备，公网 IPv4 地址也可能是正常的校园地址。两台设备互相访问不到时，可使用个人路由器或手机热点。VPN、虚拟网卡一般不是手机能访问的地址。
- 换网卡或 IP 后重新打开电脑软件，程序会重新签发服务器证书，保留原根证书。不要删除证书私钥；丢失后需要在手机重新安装信任。
- 手机存储被系统清理仍可能丢失尚未同步的修改。程序会请求持久存储，但不能保证系统永不回收。长时间离线或更换设备前，使用“导出设备备份”。

## 开发和迁移

源码开发需要 Node.js 24 或以上版本；Windows 安装包已经包含运行环境。

```text
npm ci
npm run desktop:dev
npm run desktop:package
npm run test:sync
```

`desktop:package` 先构建网站和本机后端，再生成 Windows x64 安装版和便携版。`desktop:server` 可运行已编译的本机服务，默认数据目录与客户端相同，请勿与客户端同时启动；测试时传入独立 `--data=` 目录和端口。

发布功能改动时先提高 `package.json` 及锁文件的版本，以中文提交后推送 `main`。`Windows Release` 工作流在发现未发布版本时运行检查、构建并上传安装包、便携版、差分校验文件及 `latest.yml`；全部成功后才公开正式版。同版本已经发布时不替换安装包，更新修复必须使用更高版本。也可手动触发该工作流重试未完成的草稿。只上传 `releases/` 中明确列出的程序文件，不上传私人题库、配置或备份。

从原 Cloudflare D1 迁移：`npm run desktop:migrate`。该脚本只读取线上，完整 SQL 保存在被忽略的 `.private/desktop-migration-*`。将导出导入临时 SQLite 后，检查外键、数据库完整性、每张表的记录数和 SHA-256 内容摘要，再创建本地题库。若本地题库已存在，脚本停止，绝不覆盖。也可传 `--sql=绝对路径 --data=单独目录` 导入已保存的可信完整 SQL。不要导入来源不明的 SQL 文件。

本机 AI：读取数据目录中的 `connection.json` 获得回环地址，凭证来自 `agent-credential.json`。使用 `Authorization: Bearer <token>` 调用既有 `/api/v1/agent/library`、`/api/v1/agent/schema`、`/api/v1/agent/imports/submit`。凭证仍仅绑定管理员题库。后续 Codex 整理题库应优先使用本机接口，不能再把线上旧副本当作本机最新题库。
