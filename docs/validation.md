# v1.0 验证与边界

## 可复现的本地检查

```sh
npm ci
npm run setup
npm run build
npm test
npm run test:api
npm run test:accounts
```

- 单元检查覆盖原文保留、引用校验、历史恢复、导入差异、版本冲突、JWT 签名／受众／时效、Markdown 安全渲染、会话属性和密码校验。
- 接口检查使用 `wrangler.test.jsonc` 的独立数据库，覆盖导入确认、机器权限、幂等、非法引用、并发事务、来源记录、导出与恢复。
- 账户检查使用独立临时数据库，自动构造两题的虚构旧版题库，然后迁移到多用户结构。覆盖原数据迁移、同 ID 跨用户隔离、保留管理员邮箱、角色伪造、登录、改密、退出、停用与注册开关。

演示资料只用于功能和契约验证，不对应真实公司或项目经历。检查结果写入被 Git 忽略的 `test-results/`。

## 已完成的实际运行检查

实现阶段验证过桌面页面、导入收起与数量拆分、答案编辑和追问跳转、图谱、下载后停服重载、离线复习及退出清理。

也在实际 Cloudflare 环境验证过密码计算及两用户注册登录、数据隔离、匿名读取拒绝、机器查询／草稿权限和会话撤销。临时线上测试账户与数据已清理，原有管理员题库没有改变。这不代表任何新部署自动通过；部署后仍需独立验证自己的访问规则。

`scripts/verify-online-accounts.mjs` 会在自己的部署创建两个临时测试用户，检查后仅清理本次用户及其数据；需真实部署授权，不由 CI 自动运行。`verify-password-runtime.mjs` 创建不含题库的临时 Worker，检查后清理，属于显式的线上维护检查。

## 本版限制

### 2026-10-20 导入审阅调整

- 构建、类型检查及 39 项单元测试通过，覆盖四字段审阅、附属资料折叠、Markdown 安全、更新对照、纯资料变化、恢复移除提示及过期草稿处理。
- 使用实际 Redis 21 题导入内容检查浏览器中的桌面及手机宽度排版，全部题目默认收起，题目及附属资料可折叠；手机宽度没有整页横向溢出。这是浏览器宽度验证，不替代 iPhone 真机验收。
- 此次调整前端审阅与过期处理，未改变 JSON 契约、人工确认要求、服务端版本保护或数据库迁移。
- 过期草稿修复通过 18 项独立本地 D1 接口验证：旧版本确认被拒绝且题库不变，重新预览不自动写入，人工再次确认后独立读取题库及批次证明已持久保存。
- 浏览器使用虚构资料验证版本冲突提示紧邻确认按钮，冲突后不自动再次确认；人工再次点击后显示「已应用」。线上问题草稿仅重新预览，由用户在网站确认。

### 2026-10-20 复习入口与交互反馈

- 52 项单元检查、类型检查和生产构建通过；其中 12 项复习检查覆盖范围隔离、归档排除、自然题号顺序、更新时间不影响顺序、随机不重、访问历史、方式切换、空题库及单题库。18 项独立本地 D1 接口检查通过。
- 浏览器使用虚构题库验证：首页先显示两个入口；全库跨题库发问；指定题库按 01、02、10 递进；模式切换保留当前题；随机下一题与历史返回可用；面包屑跳转清除旧筛选；指定提示语已移除。
- 复习揭晓时仅挂载提纲，完整答案在展开后加载。36 题导入预览初次打开没有挂载任何题目答案，展开一题后仅挂载该题的两个 Markdown 内容块，收起后卸载。
- 虚构接口延迟 1.6 秒时，点击掌握标记立即显示「正在保存」，服务端返回后更新掌握状态。测试记录显示范围选择、模式切换、上一题、下一题和揭晓不请求题库接口。
- 390 像素宽度浏览器页面检查了入口、出题、掌握按钮与面包屑排版；这不替代 iPhone 真机检查。
- 线上只读测量的 4 次健康请求约为 0.31～0.71 秒，机器题库读取约为 0.69～1.63 秒；大部分时间在响应首字节之前。该路径与用户会话及保存接口不同，不能把这些数字当作用户保存耗时，也不能拆分网络、验证及数据库各自占比。

### 2026-10-20 导入记录内嵌预览

- 浏览器用两批虚构记录验证预览位于所选记录下方，页面不再存在独立预览面板；切换记录时只展开对应一批，题目仍默认收起。
- 验证收起后焦点返回该记录；已应用记录禁用确认；版本冲突提示与再次确认成功状态均在原记录内显示。另一页面确认后，刷新列表会同步展开记录与预览的已应用状态。
- 新建预览后模拟列表刷新失败，新记录与预览仍可见，收起后记录仍保留。整个验证只访问本机虚构接口。

### 2026-10-20 人工导入、独立备份与设置窗口

- 81 项单元检查、类型检查和生产构建通过，覆盖人工字段验证、稳定 ID、已有 metadata 保留、普通导入／完整恢复分流、残缺备份拒绝、恢复补齐历史后的总量、管理员／普通用户设置入口。18 项独立本地 D1 接口检查通过。
- 浏览器使用虚构资料验证人工多题填写→预览→确认入库；预览后继续改答案或追加题目，再确认旧预览，后续填写保持完整并能重新预览。最终确认最新预览后清空表单。
- JSON 上传自动解析为记录内预览；备份页拒绝普通导入文件，完整备份仅在恢复记录中预览，并明确显示替换当前账号题库和移除内容。导入与备份切换保留人工填写。
- 维护页没有面试来源、账户与密码、用户管理标签；齿轮紧邻退出按钮左侧。默认设置只挂载账户内容，切换用户管理才查询管理员接口；普通用户只有账户与密码，关闭窗口后焦点返回齿轮。
- 桌面及 390 像素宽度检查了填写表单、维护标签与设置窗口。没有执行真实账户改密、启停用户或正式题库恢复。界面设计检查只报告既有全局字体和边框样式，没有改动范围内的新命中。

### 2026-10-20 图谱页面与动态交互

- 86 项单元检查、类型检查和生产构建通过；新增 5 项缩放检查覆盖滚轮单位归一化、连续缩放、指针锚点及缩放上下限。
- 浏览器使用 59 题虚构资料验证顶部标题说明、添加问题、视图切换和题目计数已移除；滚轮无需组合键，缩放比例由 18% 变为 33%，页面位置保持不变。
- 验证节点无法单独拖动，空白处拖动可平移图谱；点击节点聚焦关联，并能打开对应知识卡。暂停动态后两次截图一致，开启后可继续动态展示。
- 桌面与 390 像素宽度检查了题库选择、图谱工具栏及画布。窗口尺寸变化只调整画布，不自动重置缩放；首次操作会结束尚未完成的布局，避免延迟覆盖视图。
- 代码检查确认后台、离屏、节点聚焦及系统减少动态时暂停；超过 300 个节点采用静态圆形布局，提示选择单个题库查看动态，避免大图持续计算。手机触摸缩放及系统减少动态尚未做真机验收。
- 界面设计检测仅命中既有全局字体与边框样式，没有本次图谱改动的新命中。

### 2026-10-20 Obsidian 参考图谱与首页精简

- 本节替代上一轮关闭拖动、持续浮动及超过 300 节点静态显示的图谱行为。首页已移除最近整理标题、说明、查看全部及下方卡片。
- 93 项单元检查、类型检查和生产构建通过。新增 7 项检查覆盖题库隔离、归档排除、完整标题、有效连线、无向去重、有限初始化、参数边界，以及布局线程限速、暂停、收敛、拖动／释放确认和减少动态。
- 59 题虚构资料的浏览器验收覆盖灰色圆点与细线、节点拖动后关联自然调整且不误开卡片、单击直接打开知识卡、全库／单题库切换、滚轮缩放、搜索与设置。缩小时文字按阈值淡化，避免标签盖满图谱。
- 布局计算在独立线程，主线程按需绘制；收敛后停止绘制循环。拖动和释放使用递增确认序号，保留本地坐标直至后台确认；失焦、取消指针及隐藏页面会释放拖动状态。窗口变化不重置已操作视口。
- 独立虚构线程短测：1000 节点／1979 边的前 20 次计算平均 4.43ms、最慢 17.72ms；5000 节点／9899 边的首秒计算平均 23.18ms、最慢 65.55ms，坐标均有限。此结果不是浏览器帧率或真机流畅度承诺。
- 正式构建验证图谱脚本约 17.4KB、布局线程约 16.8KB；构建输出清单与离线预缓存均包含布局线程文件。界面检测只命中既有全局字体与边框样式。
- 手机验证为 390 像素宽度浏览器检查；双指与减少动态的真机体验仍待验收。

### 仍未完成的能力与验收

- iPhone 真机登录和离线验收仍待完成。
- 手动复习，没有间隔重复调度。
- 离线仅阅读，没有编辑队列或同步合并。
- 普通邮箱账号没有邮件验证和密码找回。
- 机器凭证只绑定管理员，不支持每用户独立凭证管理。
- Windows 一键脚本与加密凭证存储是平台专用功能；其他系统使用命令行和安全环境变量。

1.0 表示首个正式功能版本，不把这些未完成项作为已验证能力。
