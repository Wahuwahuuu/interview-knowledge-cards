# v1.0 验证与边界

## Windows 本地版与双向同步

`npm run test:sync` 使用虚构资料验证 SQLite 接口、设备与账户隔离、操作回执重试、不同字段合并、同字段及删除冲突、过期题库代次拒绝、IndexedDB 重开后的离线编辑与待同步保留。`npm run desktop:package` 生成 Windows x64 安装版和便携版。真机证书信任、校园网设备互访和 iOS 存储回收须在实际设备上验证，不能用桌面模拟代替。

迁移脚本把 SQL、内容摘要和验证报告保存在被忽略的 `.private/desktop-migration-*`。发布安装包只含程序资源，不含题库、数据库、私钥或凭证。测试不能修改线上题库。

## 可复现的本地检查

```sh
npm ci
npm run setup
npm run build
npm test
npm run test:api
npm run test:accounts
```

- 单元检查覆盖原文保留、引用校验、历史恢复、导入差异、版本冲突、JWT 签名／受众／时效、Markdown 安全渲染、会话属性和密码校验。
- 接口检查使用 `wrangler.test.jsonc` 的独立数据库，覆盖导入确认、机器权限、幂等、非法引用、并发事务、来源记录、导出与恢复。
- 账户检查使用独立临时数据库，自动构造两题的虚构旧版题库，然后迁移到多用户结构。覆盖原数据迁移、同 ID 跨用户隔离、保留管理员邮箱、角色伪造、登录、改密、退出、停用与注册开关。

演示资料只用于功能和契约验证，不对应真实公司或项目经历。检查结果写入被 Git 忽略的 `test-results/`。

## 已完成的实际运行检查

实现阶段验证过桌面页面、导入收起与数量拆分、答案编辑和追问跳转、图谱、下载后停服重载、离线复习及退出清理。

也在实际 Cloudflare 环境验证过密码计算及两用户注册登录、数据隔离、匿名读取拒绝、机器查询／草稿权限和会话撤销。临时线上测试账户与数据已清理，原有管理员题库没有改变。这不代表任何新部署自动通过；部署后仍需独立验证自己的访问规则。

`scripts/verify-online-accounts.mjs` 会在自己的部署创建两个临时测试用户，检查后仅清理本次用户及其数据；需真实部署授权，不由 CI 自动运行。`verify-password-runtime.mjs` 创建不含题库的临时 Worker，检查后清理，属于显式的线上维护检查。
