# 账户与管理员

普通用户用邮箱账号和至少 12 个字符的密码注册，题库初始为空。邮箱目前作为账号标识使用，v1.0 没有发邮件验证或密码找回。密码可在「维护与备份 → 账户与密码」修改；其他设备随后需要重新登录。

部署时的 `OWNER_EMAIL` 保留给管理员，不能从普通注册页抢先注册。部署拥有者首次配置时直接打开受保护的 `/bootstrap-admin/` 验证自己邮箱，再亲自设置密码，随后用网站账号密码登录。不提供默认生产密码。公开首页和登录页不展示管理员初始化入口；设置好密码的管理员使用与普通用户相同的登录表单。

管理员在「维护与备份 → 用户管理」查看用户、启用／停用普通账户、开放／关闭注册。停用会保留数据并撤销会话；管理员不能在此停用自己，也没有通过管理页查看他人题库的功能。v1.0 只有部署拥有者这一个管理员，不提供角色提升入口。

每个账号分别维护自己的项目、卡片、知识点、来源、出现记录、问题关系、导入草稿和历史。相同卡片 ID、批次 ID 可以存在于不同账户。备份和恢复也只作用于当前用户。

AI 服务凭证绑定管理员题库，仅查询和提交草稿。普通用户可以让 AI 生成 JSON 文件，登录自己的账户后上传。任何正式导入都由对应用户人工确认。

退出登录和切换账号会清理本机已下载的私人题库。离线退出先清理数据，联网后撤销旧会话。不同设备上的已下载资料需要各自更新或清理；账号停用不能抹除此前已下载到其他离线设备的文件。

忘记普通用户密码时，v1.0 没有自助恢复入口；请妥善保存自己的密码。管理员首次设置路径只支持初始化，不是密码重置服务。
