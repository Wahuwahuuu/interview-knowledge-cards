# 网站与 Windows 客户端自动同步

2.1.0 起，手机使用线上网站编辑，Windows SQLite 自动接收；本地编辑断网保存，联网后自动上传。无需同一 Wi-Fi，电脑关闭时网站独立使用。同步以用户主动连接的网站账号为边界，不使用 AI 管理员机器凭证。

## 首次连接

1. 将 Windows 客户端更新到 2.1.0 或更新版本，保留原有数据目录。安装版在齿轮 → 软件更新里重启更新，便携版换用新版程序。
2. 在电脑浏览器打开线上网站，登录自己要同步的账号。齿轮 → **网站同步** → **生成电脑连接码**。连接码五分钟有效，只能使用一次。
3. 打开客户端齿轮 → **网站同步**。填写网站的完整 HTTPS 地址、连接码和电脑名称，点击 **读取网站题库**。不要填写电脑的局域网 IP。
4. 核对显示的网站账号和两边在用卡片数量，点击 **确认合并并开启自动同步**。开始前自动保存本地完整 SQLite 备份到 `backups/before-website-sync-时间.sqlite`。
5. 等待 **已与网站同步**。如出现两边不同修改，核对显示的题目、字段和两个版本后选择；不要反复生成连接码。

网站与本机账号不必有相同邮箱；连接码明确授权的是网站当前登录账号，本机绑定的是客户端当前账号。不同本机账户分别连接，不共享网站令牌。核对账号可避免把两个人的题库混在一起。

## 日常使用

- 手机继续打开原网站，修改并保存即可。电脑端无需手动导入，软件运行且联网时会接收；关机期间修改保存在网站，电脑重开后继续。
- 电脑本地保存不等待公网请求。保存后约 1.5 秒触发上传，后台约每 20 秒检查网站；失败后自动重试。网页前台约每 10 秒检查题库，客户端界面约每 5 秒检查本机版本，回到前台也会检查。它是自动同步，不保证每次按键立即出现在另一台设备。
- 客户端底部同步状态可打开设置，查看上次完成时间、立即同步或暂停。窗口中有未保存编辑时不会用新题库替换草稿；保存遇到版本冲突时按现有提示重新核对。
- 电脑访问网站需要代理时，在“网络设置”填写已经运行的本机 HTTP 代理地址，例如 `http://127.0.0.1:7897`。无代理时留空。程序不关闭 HTTPS 验证、不修改系统代理，也不保证解决手机网络本身的访问限制。
- 同一字段的不同修改保留双方，当前界面的“全部采用网站版本／全部保留本地版本”处理本批全部冲突，并弹出确认。也可先到知识卡编辑中手动合并，再点“重新检查”。断网、关闭软件和重启均不清除待同步操作。
- 网站“已连接的客户端”可二次确认后撤销。客户端“解除连接”也需确认，保留两边题库。修改网站密码或停用网站账户会撤销设备权限，需要重新生成连接码。

## 合并与数据边界

首次在网站设置生成一次性连接码，客户端读取账号与题库数量后，经用户确认才合并并开启同步。首次合并保留两边独有记录；同 ID 不同内容保留双方供选择，不以更新时间覆盖。之后使用持久化共同基线、逐字段三方合并及带回执的操作；回执与写入同一事务提交，网络失败不移除待同步操作。

同步范围为项目、知识大类、题目、口述版、完整答案、主追问、来源与出现记录，以及掌握／收藏／重点。账户密码、用户管理、机器凭证、程序更新和数据库备份不跨设备复制。两端各自保留历史，新到达的答案由本端正常保存流程记录版本，不把两边独立修订号直接覆盖。导入题目随内容同步，导入结果记录保留在执行导入的一端。

已通过原界面二次确认的删除随同步传播；删除与编辑冲突需要选择，不复活旧设备已删记录。完整恢复改变题库代次，自动同步暂停，重新核对后才能继续。首次合并前备份本地 SQLite，停止同步不清除任一端题库。

同步服务使用独立、按账号限定的设备令牌，只能调用同步协议，不能管理用户、恢复题库或访问其他账号。网站中可撤销设备，密码或账户状态改变会撤销连接。客户端令牌通过 Windows 用户加密保存，界面和日志不返回令牌。网络请求不占用 SQLite 操作队列，后台同步不会让翻卡和本地保存等待公网响应。

生产题库只在用户完成连接及首次合并确认后参与自动同步。恢复完整备份后，需要先解除连接，再用新连接码重新读取、核对并合并；不要直接继续发送恢复前的操作。

公网网站项目下载仍为离线阅读副本，手机在公网网站编辑需要联网；可选的局域网配对 PWA 离线编辑能力保持。iOS 不保证后台页面持续执行，请回到网站前台核对保存结果。

## 实现入口

- `worker/cloud-sync.ts` 与 `migrations/0004_cloud_sync.sql`：一次性连接码、设备授权、轻量版本查询及事务回执；设备凭证只有当前网站账号的同步权限。
- `desktop/cloud-sync.ts`：独立于本机数据库队列的网络任务，共同基线、持久发件操作、恢复代次保护、冲突与重试。本机链接保存在 `desktop_settings`，不随题库 JSON 导出。
- `src/CloudSyncView.tsx`：网站生成／撤销连接，客户端连接、首轮核对、状态与冲突。原局域网配对留在“本机与局域网”。
- `npm run test:sync` 包含网站同步用例，具体本轮验证见 [验收记录](validation.md)。

技术依据：[D1 batch 事务](https://developers.cloudflare.com/d1/worker-api/d1-database/)、[Electron 本机加密](https://www.electronjs.org/docs/latest/api/safe-storage)。
