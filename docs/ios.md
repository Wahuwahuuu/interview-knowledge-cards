# iPhone 复习

日常使用继续采用线上网站：手机可使用蜂窝网络，或任何能够访问网站的 Wi-Fi；不要求电脑开机、连接同一个 Wi-Fi、安装本机证书或生成配对码。手机和电脑登录同一网站账号，在线复习、编辑和标记直接保存到该账号的线上题库。

Windows 2.1.0 起支持本地 SQLite 与网站自动双向同步。首次按 [网站同步说明](cloud-sync.md) 在网站生成连接码、客户端核对并确认合并；以后手机仍打开原公网网站即可，电脑关闭时也能在线修改。电脑下一次运行并联网后接收网站改动，本地改动自动回传。不同字段自动合并，同字段冲突在客户端处理；无需更换手机网址、安装证书或连接同一 Wi-Fi。

下面的下载步骤适用于线上网站，其离线副本仍以阅读为主。可选的本机配对 PWA 支持离线编辑，说明见 [Windows 与 iPhone 配对说明](desktop.md)；该入口仅用于能连接电脑局域网的场景，不把公网网址替换为电脑的局域网 IP。

1. 在 Safari 打开自己的在线部署网址，用邮箱账号和密码登录。
2. 使用分享菜单选择「添加到主屏幕」；之后从桌面图标进入。按钮位置以当前 iOS 为准，参见 [Apple 官方说明](https://support.apple.com/en-in/guide/iphone/iph42ab2f3a7/ios)。
3. 联网进入一个项目，点击「下载项目」，等到成功提示。
4. 关闭 Wi-Fi 和蜂窝网络，重新打开，检查能否阅读、揭晓答案、切换题目和查看项目图谱。

离线副本按设备保存，显示下载时间。图谱可以拖动和缩放，点击问题节点打开卡片。离线阅读不会保存新的收藏、掌握状态、答案或来源；修改需要联网。

在线打开的页面会定期检查题库版本，回到前台也会检查；编辑未保存时保留当前草稿，不自动替换。已下载副本需要点击「更新离线内容」更新。电脑改答案后，等待客户端显示「已与网站同步」，再在手机核对并更新下载。退出登录会清除当前设备的下载。

首次验收应在实际 iPhone 完成登录、主屏幕打开、下载后重开、断网翻卡和图谱，以及电脑和手机读到相同新答案。桌面截图、响应式样式和模拟尺寸不能代替真机检查。v1.0 发布时，真机验收仍待完成。
