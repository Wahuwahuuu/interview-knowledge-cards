# 主问题分组预览

本功能已从 `codex/main-question-cards` 合并到 `main`。下文保留本机只读预览方法；本次合并不包含线上发布。

## 统计口径

- 首页总数、侧栏题库数、项目卡片、题库列表、离线题库摘要及自测选择器均按主问题计算。示例：4 道主问题附带 8 条子问题，题库数量显示为 4。
- 只有同一项目内有效的 `followup` 关系会把子问题收进主问题。`related` 关系不影响统计；跨项目的追问关系继续保留在详情中，各项目统计仍可相加。
- 已掌握数量和进度按主问题自身的掌握状态计算；子问题的独立状态保留，显示在展开后的列表中。
- 默认排除归档卡片。父卡不在当前范围内时，子问题仍可作为主问题找到；历史循环使用稳定入口，避免内容消失或无限遍历。
- 导入记录的实际写入张数及完整备份内容保持原有含义，不按展示分组缩减数据。

## 展示与交互

卡片模式默认只平铺主问题。有子问题的主卡带两层浅绿色纸片轮廓，展开时纸片收拢，子问题列表在约 260 毫秒内展开。子问题逐行显示，点击即可打开原有详情和编辑、删除等入口。列表模式采用相同分组方式。

搜索、知识点、收藏、重点或状态筛选命中子问题时，保留它的主问题作为上下文，并自动展开匹配结果。筛选后数量按当前结果中的主问题计算。收起内容退出键盘和辅助技术的可访问范围；系统要求减少动态效果时，关闭位移和展开动画。

颜色、字体、圆角与原网站保持一致；只在主卡上增加纸片层次和轻微阴影，没有引入新的动画依赖。

## 本机预览

在项目目录运行：

```powershell
npm ci
npm run build
npm run preview:groups
```

默认使用虚构的示例题库，地址为 `http://127.0.0.1:5291`。预览仅绑定本机，拒绝所有写入请求。可以通过 `--library` 指定保存在被忽略目录中的题库快照：

```powershell
npm run preview:groups -- --library "本机题库快照.json"
```

个人题库快照不进入提交或构建资源。
