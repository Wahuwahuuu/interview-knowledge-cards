# Windows 本地版与 iPhone 同步

## 数据归属

Windows 安装包使用 Electron，界面仍由现有 React 代码生成；Hono 接口在本机运行，使用 Node 内置 SQLite。题库、账户、密码摘要、来源、归档、关系、历史和导入记录沿用现有表结构。数据保存在 Windows 用户目录，与程序升级分离。旧线上题库保留；迁移先导出完整数据库，再导入新文件并核对各表数量及内容摘要，不能以旧缓存覆盖线上最新数据。

iPhone 的 PWA 保存当前配对账户的完整副本和持久化待同步操作。保存成功表示 IndexedDB 事务已提交；只有电脑确认提交 SQLite 后，才移除待同步操作。退出、解除配对或清理数据前检查待同步记录，先同步或导出。手机的浏览器存储仍可能被系统清理，尚未同步的内容不能声称已备份。

## 同步协议

- 电脑通过 SQLite 事务内的日志触发器记录实体、历史和导入记录的增删改，游标取数据库提交序列。
- 手机发送唯一操作 ID、每个实体的修改前内容和修改后内容。电脑逐字段做三方比较：不同字段合并；相同字段不同修改、删除与修改、引用冲突保留双方，交给用户处理。
- 每次操作（包括关联记录）整体成功或整体失败。操作回执、实体修改、日志在同一事务中提交；网络断开后可以安全重试。
- 手机拉取自上次游标以来的增量，并在最新电脑副本上重放尚未确认的操作。更新同步状态和副本使用同一个 IndexedDB 事务。
- 删除日志作为墓碑保留，旧设备的编辑不会使已删除记录自动复活。完整恢复产生新的题库代次；旧设备必须先处理待同步内容，再接受新副本。
- 账户隔离、主追问关系、原始来源保护和数据校验继续使用现有契约。机器凭证只绑定管理员，只提供读取与普通导入。

## 连接与信任

桌面窗口只访问回环接口。手机通过同一 Wi-Fi 下的 HTTPS 访问本机接口；服务端为本机生成独立证书，私钥留在电脑。首次在 iPhone 安装并信任本机根证书，再添加到主屏幕，最后在主屏幕应用内输入桌面生成的限时配对码。配对码不放入网址；设备令牌可在桌面撤销。公开的 HTTP 引导页只提供证书和连接说明，不提供题库和写接口。电脑关闭或不可达时，手机继续离线编辑，重新打开应用或点击同步后重试。

## 交付与验证

实现顺序：本机 SQLite/Hono 兼容层 → 事务同步与冲突 → PWA 持久编辑 → 桌面包装与 HTTPS 配对 → 完整数据库迁移。检查覆盖回执重试、字段合并、冲突与删除、游标、账户隔离、离线重启保存、备份及现有功能构建。真实 iPhone 的证书安装和系统存储行为须由设备端完成验证。
