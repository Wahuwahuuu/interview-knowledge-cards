# 备份与恢复

在「维护与备份 → 备份与恢复」下载完整 JSON。它包括当前账号的项目、卡片、原始来源、出现记录、知识点、关系、收藏和掌握状态，以及答案历史。账号、密码与登录会话不包含在题库备份中。

恢复时点击「选择备份并预览」上传该 JSON，先在恢复记录中查看包含新增、修改和移除在内的差异，再确认。普通问题导入文件不能作为完整备份恢复。完整恢复会替换当前账号的题库，不影响其他用户。预览之后题库有变化时，重新预览再确认，不能直接覆盖另一台设备上的修改。

点击「确认恢复备份」后还会出现独立确认弹窗，显示将移除的题目数量；点击「确认恢复」才真正替换题库。取消、关闭或按 Esc 都不会恢复或删除资料。删除项目或知识卡后，可通过删除前导出的完整备份恢复；恢复会同时替换备份之后的其他改动，应先核对预览。

目前上传恢复文件上限为 8 MB。超过上限请保留完整文件，不要拆分后依次恢复；每次恢复都会替换整个题库。

Markdown 是阅读版，便于存档和阅读，不作为无损恢复格式。分享备份前请自行核对其中的面试公司、经历、原始问答与本机源码路径。

升级数据库 schema 前，部署维护者另外使用 Cloudflare D1 导出／Time Travel 保留整个数据库。整库备份包含所有用户和密码摘要，属于私有维护资料，不能放进公开仓库或 Release；恢复整库是部署维护操作，与网页个人题库恢复不同。

仓库 `.gitignore` 排除了数据库、`.private/`、真实配置、导出文件和检查记录。源码 Release 只含程序、通用文档和虚构示例。不要把个人问答放进 `public/` 或前端源码，因为这些内容会进入网页构建资源。
